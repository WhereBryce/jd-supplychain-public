01 · WHY

项目背景：赠品不是“没有货”，而是难以下沉到合适的位置

宝洁给京东的赠品目前按整箱下沉。受箱规、赠品配额与最小起运量约束，并非每一个直送城市都能分到一箱。

当下沉城市有主品却没有赠品，而上游城市同时有主品和赠品时，消费者订单可能优先从上游整单代发。这会增加配送费用，也会牺牲本地库存带来的时效价值。反过来，如果为了覆盖而向低销量城市强行下整箱，又可能形成低周转与滞销。

BBCC 在这个场景中的价值假设 先把赠品集中送到 B 仓，再由 B 仓按支、少量、高频地补给 C 仓，以更小的库存颗粒度换取更广的城市覆盖。

因此，这次仿真要回答的并不是“BBCC 理论上好不好”，而是一个更具体的问题：若历史赠品货量改走三个 B 仓，并按城市需求拆支补给，年度毛费用是多少？调拨频次如何影响费用？

02 · MODEL

仿真框架：从历史货量到逐条 B-C 任务

模型采用确定性计算，不使用生成式预测。核心粒度是“月份 × SKU × B 仓 × C 仓 × 调拨情景”。

  1. 确定赠品范围。以洗护发赠品清单为边界，读取 JD 码、箱规、首件出库费和续件出库费。
  2. 形成月度需求基线。从 FY2526 宝洁对京东发货记录汇总各 SKU 每月的支数、体积和重量。
  3. 计算城市分布。使用库存快照中各 SKU 的近 90 日收货地商品件数，仅向历史销量大于 0 的城市分配。
  4. 收敛到直送城市。非直送配送中心先按区域关系收敛到宝洁应发货的 C 仓城市；无法映射的份额不重新放大。
  5. 确定固定 B-C 映射。对每个 C 仓分别试算廊坊、苏州、广州三条线路，以“每日调拨”年度运输费最低者作为固定 B 仓。
  6. 运行三种频次。固定同一套 B-C 映射，分别模拟每个法定工作日、每周 2 次、每周 1 次。
SKU-城市占比 = 该 SKU 在目标城市的近90日收货地商品件数 ÷ 该 SKU 在全部正销量城市的近90日收货地商品件数 SKU-城市月需求 = SKU月度历史发货量 × SKU-城市占比

03 · COST LOGIC

费用公式：运输看单次重量，出库看唯一首件

宝洁 → B 仓

3个B仓 × 2次/月 × 1,000元/次 × 12月 = 72,000元/年

B 仓 → C 仓运输

体积重量kg = m³ × 1,000,000 ÷ 5,000 = m³ × 200 单次计费重量kg = MAX(实际重量kg, 体积重量kg) 单次运输费 = 单次计费重量 × 对应线路公斤段报价

公斤段在单次调运任务层面判断：不超过 1,000kg 使用小公斤段报价，超过 1,000kg 使用大公斤段报价。

B 仓调拨出库

单次任务先按 SKU 拆整箱与散支。整箱按箱计费；全任务所有 SKU 的散支合计只收一个首件，选择首件费最高的散支 SKU，其余按各自续件费。若全部为整箱，则不收首件或续件费。

整箱数 = FLOOR(SKU任务支数 ÷ 箱规) 散支数 = SKU任务支数 - 整箱数 × 箱规 SKU整箱费 = 整箱数 × 整箱出库费每箱单价 例如：箱规24、任务量48.3支 = 2整箱 + 0.3散支

保费与折扣

假设赠品货值 = 3元/支 保费 = 调拨支数 × 3元 × 0.05% 折后实付 =（宝洁-B运输 + B-C运输）× 60% +（B仓出库 + B仓存储）× 50% + 保费 其中：B仓存储费假设为0，保费不参与折扣。

  3. 整箱费：1 箱 × ¥1.50 = ¥1.50/任务。
  4. 散支费：全任务只收一个首件 ¥2.80；扣除首件后的续件费为 ¥6.5123，因此散支费 ¥2.80 + ¥6.5123 = ¥9.3123/任务。

为什么频次会影响成本？ 低频会提高单次 SKU 集中度，更多支数转为低价整箱，同时减少散支首件次数。这是新版结果中每周 1 次明显低于每日情景的主要原因。

06 · DECISION BOUNDARY

如何使用这份结果

本模型回答的是 BBCC 链路的毛费用，尚不能单独回答“项目是否值得做”。完整商业判断还需要补入：

  • 现状因赠品缺货产生的上游代发费用；
  • 当前赠品直送的运输与操作成本；
  • 整箱下沉造成的滞销、报废或资金占用；
  • 覆盖与时效改善带来的潜在销售增量；
  • 低频调拨对 C 仓安全库存和服务水平的影响。
数据边界 约 0.12% 历史货量未纳入：一部分 SKU 在参考快照中没有正销量城市；另有一个目标城市缺少三个 B 仓的线路报价。模型没有用默认价静默填补，而是保留为异常。

下一步建议用同一城市与 SKU 粒度估算“避免代发 + 避免滞销”的收益，再与本页毛费用相减，形成三种调拨频次的净收益和盈亏平衡点。
